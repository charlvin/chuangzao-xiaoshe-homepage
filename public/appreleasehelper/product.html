From “what now?” to the next clear step

Built an app but got stuck on certificates, Bundle IDs, Privacy Manifests, screenshot sizes, or review requirements? AppReleaseHelper uses your platform, distribution method, business model, account system, and SDK usage to keep only the steps relevant to your project.

Key features

Submission Checklist

Generate a tailored checklist for each project. Progress is stored independently, so applicable steps can be recalculated whenever the project changes.

Project Doctor

Check an Xcode project for common issues involving signing, App Sandbox, deployment targets, App Icons, and Privacy Manifests.

Screenshots and App Icons

Check image proportions, export common App Store screenshot sizes, and turn one source image into iOS or macOS App Icon resources.

Privacy Policy Generator

Create an editable Markdown draft based on your project's data practices. It is a starting point, not legal advice.

Distribution Script Generator

Generate local packaging, notarization, and release scripts for other projects using Developer ID distribution.

Rejection Reference

Look up common App Review Guideline and ITMS errors, likely causes, and possible fixes while offline.

FAQ

Can the app read my entire disk?

No. The app runs in a sandbox and receives access only after you explicitly select a file or folder through a macOS system panel.

Does it download rule updates automatically?

No. The app does not connect to the network. Reference packs are updated only when you manually import a local JSON file.

Does it guarantee App Review approval?

No. It helps organize and check release preparation, but Apple makes the review decision and its requirements can change.

Is a DMG available from this website?

No. AppReleaseHelper is distributed only through the Mac App Store.

常见问题

App 会读取整个磁盘吗？

不会。App 运行在 Sandbox 中，只有你通过 macOS 系统面板明确选择文件或目录后，才会获得相应访问权限。

App 会自动下载最新规则吗？

不会。App 不联网。规则资料更新由你手动选择并导入本地 JSON 文件。

App 能保证审核通过吗？

不能。它帮助整理和检查准备工作，但审核结果由 Apple 决定，且规则会持续变化。

是否提供官网 DMG 下载？

不提供。AppReleaseHelper 仅通过 Mac App Store 分发。
